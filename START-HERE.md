# Раздельная маршрутизация VPN для Windows

Этот архив можно целиком передать своему агенту. Он содержит переносимый навык, подробную инструкцию, шаблоны и скрипты. Подготовлено 23 ноября 2026 года.

Схема рассчитана на Windows 10/11 и VPN, который создаёт отдельный сетевой адаптер. Российские сайты открываются через провайдера, остальные — через подключённый VPN. Для выбора маршрута используется Mihomo, тот же движок, который работает в Clash Verge Rev. Каждый сайт выбирается по правилам автоматически.

## Что написать агенту

Скопируйте это сообщение и приложите архив или путь к распакованной папке.

```text
Используй навык windows-vpn-split-routing из этого архива и настрой схему на моём Windows-ПК.
Прочитай SKILL.md, references/setup.md и references/verification.md.
Определи мои сетевые адаптеры, VPN, свободные порты и существующие настройки самостоятельно.
Российские сайты, Авито, Яндекс и Банк Точка направь через провайдера.
Остальные сайты направь через мой подключённый VPN.
Настрой автозапуск и восстановление после входа в Windows.
Проверь реальные маршруты, основной браузер и приложения с собственным прокси.
Если на ПК есть Hermes и нужен его браузер, используй ту же схему для выделенного Edge.
Сохрани локальный отчёт и возможность отката.
Выполни настройку до конца, пользуясь доступной информацией и разумными локальными решениями.
Если для VPN или сайта нужен мой вход, подготовь всё остальное и сообщи точное действие.
```

Для Codex можно скопировать папку `windows-vpn-split-routing` в каталог навыков своего экземпляра Codex и вызвать `$windows-vpn-split-routing`. Другой агент может прочитать `SKILL.md` напрямую. Навык самодостаточен внутри своей папки.

## Как пользоваться после настройки

| Ситуация | Действие владельца | Что происходит |
|---|---|---|
| Нужны и российские, и зарубежные сайты | Подключить VPN один раз и оставить маршрутизатор включённым | Российские домены идут напрямую, остальные через VPN |
| Открывается Авито, банк или Яндекс | Оставить VPN подключённым | Правила отправляют эти запросы через провайдера |
| Работает выделенный Edge агента | Оставить его локальный прокси настроенным | Для фонового браузера действуют те же правила |
| VPN отключился | Подключить его повторно | Внешние сайты возобновляют работу после восстановления VPN |
| На старте Windows интернета нет | Дождаться подключения VPN и запуска ядра | Системный прокси начнёт отвечать после готовности компонентов |
| Сегодня нужен обычный интернет при выключенном VPN | Выполнить описанный откат системного прокси, затем выключить VPN | Приложения возвращаются к исходным настройкам |

При данной политике внешние сайты требуют рабочего VPN. Ядро уже работающей схемы может продолжать обслуживать прямые соединения при обрыве VPN. Холодный запуск входящего супервизора ждёт оба адаптера. Переключение между сайтами выполняется автоматически, ручное включение VPN для каждой вкладки не требуется.

Системный прокси действует на приложения, которые его используют. Настройки Яндекс Диска, отдельного Edge и других приложений агент проверяет отдельно. Платный VPN, подписка и собственные авторизации на сайты настраиваются владельцем на его компьютере.

## Что находится в архиве

| Файл или папка | Назначение |
|---|---|
| `windows-vpn-split-routing/SKILL.md` | Входная инструкция для агента |
| `references/setup.md` | Полная установка и выбор адаптеров |
| `references/verification.md` | Проверка IP, правил, приложений и перезагрузки |
| `references/browser-and-hermes.md` | Выделенный Edge, фоновый режим, ручной вход и Hermes |
| `references/troubleshooting.md` | Диагностика и откат |
| `references/sources.md` | Официальные источники и ограничения схемы |
| `assets/routing-policy.json` | Редактируемый список направлений |
| `assets/mihomo.template.yaml` | Читаемый шаблон для ядра и Clash Verge Rev |
| `scripts/` | Обнаружение сети, генерация конфигурации, запуск, системный прокси, проверка выходов |
| `MANIFEST.sha256` | Контрольные суммы файлов комплекта |

Архив подготовлен заново из общих инструкций и публичных технических параметров. Рабочие профили, ключи, IP-адреса, подписки, логи, личные пути и данные аккаунтов в комплект не включаются. Скрипты создают локальные файлы уже на компьютере получателя.
