# Windows VPN Split Routing

Agent-ready toolkit for Windows 10/11 that routes Russian websites directly through the ISP and sends other traffic through an already connected VPN adapter. The local router is [Mihomo](https://github.com/MetaCubeX/mihomo); its binary and VPN credentials are not included.

## Быстрый старт

1. Скачайте архив из раздела **Releases** или клонируйте репозиторий.
2. Передайте комплект своему локальному агенту.
3. Попросите начать с [`START-HERE.md`](START-HERE.md).

В `START-HERE.md` уже находится готовое сообщение для агента. Агент самостоятельно определяет сетевые адаптеры, VPN, свободные порты и существующие настройки. Владелец выполняет только вход в VPN, MFA и ручные проверки сайтов, если они потребуются.

## Что настраивается

- `.ru`, `.рф`, Авито, Яндекс и Банк Точка — через физический интерфейс провайдера;
- остальные сайты — через существующий VPN-адаптер;
- локальный HTTP/SOCKS-прокси Mihomo на loopback;
- системный прокси текущего пользователя;
- автозапуск и восстановление после входа в Windows;
- проверка реальных выходов, браузера и приложений с собственным прокси;
- локальный отчёт и безопасный откат.

## Требования и ограничения

- Windows 10/11 и PowerShell 7.2+;
- VPN должен создавать отдельный сетевой интерфейс Windows и допускать привязку соединений к физическому интерфейсу;
- схема охватывает приложения, использующие системный HTTP/SOCKS-прокси; произвольный UDP и приложения с собственным сетевым стеком требуют отдельной настройки;
- при выключенном VPN внешние сайты по данной политике могут быть недоступны;
- некоторые VPN-клиенты блокируют прямой выход с помощью kill switch или Windows Filtering Platform — это выявляется проверкой из комплекта.

Перед применением обязательно прочитайте разделы проверки и отката. Не отключайте Mihomo, оставляя системный прокси направленным на его локальный порт.

## Приватность

Репозиторий не содержит VPN-профилей, ключей, подписок, токенов, cookies, публичных IP-адресов, логов или браузерных профилей. Обнаруженные на конкретном компьютере сведения сохраняются локально и не должны публиковаться.

Не добавляйте в issues или pull requests:

- `%LOCALAPPDATA%\VpnSplitRouting`;
- `network-snapshot.json`;
- `routing-settings.json`, сгенерированный на конкретном ПК;
- журналы Mihomo/VPN;
- снимки прокси, профили браузеров и любые учётные данные.

## Состав

- [`START-HERE.md`](START-HERE.md) — готовое задание агенту;
- [`windows-vpn-split-routing/SKILL.md`](windows-vpn-split-routing/SKILL.md) — входная инструкция навыка;
- `references/` — установка, проверка, браузеры, диагностика и источники;
- `assets/` — переносимая политика и шаблон Mihomo;
- `scripts/` — обнаружение сети, генерация конфигурации, супервизор, системный прокси и проверка выходов;
- [`MANIFEST.sha256`](MANIFEST.sha256) — контрольные суммы файлов исходного комплекта.

## Безопасность

Скрипты изменяют системный прокси только для текущего пользователя и сначала сохраняют исходные значения. Они не содержат VPN-учётных данных и не меняют общесистемную политику выполнения PowerShell. Перед публикацией локальных отчётов обезличьте пути, адаптеры и журналы посещений.
